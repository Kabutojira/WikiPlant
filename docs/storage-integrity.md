# Storage integrity and concurrency

Canonical files are UTF-8 raw Markdown/CSV/JSON/YAML mapped by exact Drive ID and MIME type. Before replacement, fetch full current content, verify instance scope and binding, and record input hash/revision plus intended output hash in a durable operation. Update the same ID with a proved precondition when exposed, then independently read back. Native Docs/Sheets look-alikes are rejected.

V2 `SafeWriter.replace` requires the exact `FileSnapshot` used to generate the content as `base=`. Immutable intent and completion artifacts preserve original instance/target/base/output identity. Reusing an operation ID with another target/content/base conflicts. Completed replay returns `WriteReceipt.verified_sha256`/`verified_revision` for history and `current` for the currently observed target; it never rewrites later manual edits. Scope validation walks actual parent IDs for target, journal, inbox and backup destinations. Immutable creates reconcile paginated inventory and exact readback after lost responses.

The local strong fake exposes conditional writes and idempotent creates; the deliberately weak fake has neither guarantee. The latter can retain immutable intake with conflict reconciliation but cannot materialize canonical content. `DailyRunStore` additionally requires an observed whole-execution serialization guard before reserving/executing work, because conditional file updates alone do not exclude duplicate external research. No real connector guarantee is inferred from either fake. Host serialization, raw freshness and overlap acceptance remain NOT RUN.

Cross-file transactions are not assumed. Research/source records and wiki changes are verified before successful queue removal. Report publication retries are independent of research. Lost write responses are reconciled by operation ID, target ID, and hash before retry.

Interactive and weekly inputs use unique command/proposal files when an exclusive canonical writer cannot be established. The single canonical writer rebuilds from fresh current projections plus durable inputs. Forced conflicts fail closed and retain inputs. Pagination is mandatory; partial indexed text is never a replacement base. Residual risk from arbitrary simultaneous manual edits remains a live acceptance item.
