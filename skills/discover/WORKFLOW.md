# Bounded adjacent discovery

Inspect a finite set of relationships, research gaps, source leads, and saved project needs after primary-topic monitoring. Prefer diverse, potentially consequential connections over volume. Stay within the approved semantic purpose and the configured automatic-root admission ceiling. Never change core primary topics, permissions, schedules, budgets, or runtime.

Deduplicate against pending/completed work and causal chains. A genuinely independent external event may create a root with provenance and reason; rediscovery, relabeling, urgency, or a new run ID cannot reset lineage. Persist admitted questions before reporting them. Excluded but useful ideas may remain labeled hypotheses with a recorded reason, not hidden executable work.
